# flask-k8s-pipeline

A containerized Python service deployed to a local Kubernetes cluster, with an
automated CI pipeline. Demonstrates Docker multi-stage builds, Kubernetes
deployments with health-checked self-healing, and GitHub Actions CI/CD.

## Tech Stack
- **App**: Python / Flask
- **Container**: Docker (multi-stage build)
- **Orchestration**: Kubernetes (minikube, local)
- **CI/CD**: GitHub Actions
- **Observability**: Prometheus metrics endpoint
